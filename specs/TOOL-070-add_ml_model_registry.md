## 2. Purpose

The `fastapi_add_ml_model_registry` tool adds a production-grade, database-backed ML model artefact registry to a FastAPI project. It is framework-agnostic at its core: no ML library (torch, scikit-learn, tensorflow, xgboost, etc.) is imported at any level. The registry is a pure SQLAlchemy 2.0 + FastAPI service that tracks metadata — version strings, artefact paths, framework names, metrics JSON, and lifecycle status — and manages the full promote/rollback lifecycle.

Teams building ML-backed services routinely face the "where did that model come from?" audit failure when a model is promoted without a record of which version was in production, what its accuracy was, and whether the promotion was intentional. The `jobs` table or in-process `ModelRegistry` singleton from TOOL-068 do not solve this: the jobs table records task executions, not model artefacts; the in-memory registry resets on every restart and has no promote/rollback semantics. This tool addresses all three gaps by generating (a) an `MLModel` SQLAlchemy model with a `status` column implementing the lifecycle state machine `registered → staging → production ↔ archived ↔ rolled_back`; (b) Pydantic v2 schemas for create, read, promote, and compare operations; (c) seven async CRUD helpers covering `register`, `get_by_version`, `get_active`, `list_versions`, `list_all`, `promote`, `rollback`, and `compare_metrics`; (d) a `RegistryService` facade class that wraps the CRUD layer with business logic — including an `ab_split` method that persists rollout percentages to the `feature_toggles` table when `add_feature_toggles_api` is installed, or returns a stub acknowledgement otherwise; (e) seven HTTP endpoints under `/ml/models`; and (f) an Alembic migration chained to the current head via `find_migration_head` so it does not create a fork in the migration graph.

The tool adds **no new packages** to `requirements.txt`. All generated code uses FastAPI, SQLAlchemy 2.0, and standard library primitives already present in any project generated by `fastapi_generate_project`. The idempotency fingerprint is `"class MLModel"` in `app/models/ml_model.py`.

```python
class MLModel(Base):
    """A versioned ML model artefact entry in the registry.

    Status transitions:
        registered → staging → production
                              ↗
            rolled_back ←────  (rollback restores previous production version)
            archived    ←────  (previous production is archived on promote)
    """

    __tablename__ = "ml_models"

    id: Mapped[uuid.UUID] = mapped_column(Uuid, primary_key=True, default=uuid.uuid4)
    name: Mapped[str] = mapped_column(String(128), nullable=False, index=True)
    version: Mapped[str] = mapped_column(String(64), nullable=False)
    artifact_path: Mapped[str] = mapped_column(String(512), nullable=False, default="")
    framework: Mapped[str] = mapped_column(String(64), nullable=False, default="unknown")
    metrics_json: Mapped[dict | None] = mapped_column(JSON, nullable=True)
    status: Mapped[str] = mapped_column(String(32), nullable=False, default="registered", index=True)
    promoted_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True), nullable=True)
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now(), nullable=False,
    )

    __table_args__ = (
        Index("ix_ml_models_name_version", "name", "version", unique=True),
    )
```

### 4.4 CRUD promote / rollback: AFTER

```python
# app/crud/ml_model.py (excerpt)
async def promote(session: AsyncSession, name: str, version: str) -> MLModel | None:
    """Promote *version* to production; archive the previous production row."""
    target = await get_by_version(session, name, version)
    if target is None:
        return None
    await session.execute(
        update(MLModel)
        .where(MLModel.name == name, MLModel.status == "production")
        .values(status="archived")
    )
    target.status = "production"
    target.promoted_at = datetime.now(timezone.utc)
    await session.flush()
    await session.refresh(target)
    return target

async def rollback(session: AsyncSession, name: str) -> MLModel | None:
    """Roll back current production; restore the most-recently archived version."""
    current = await get_active(session, name)
    if current is None:
        return None
    current.status = "rolled_back"
    result = await session.execute(
        select(MLModel)
        .where(MLModel.name == name, MLModel.status == "archived")
        .order_by(MLModel.promoted_at.desc())
        .limit(1)
    )
    previous = result.scalars().first()
    if previous is None:
        return None
    previous.status = "production"
    previous.promoted_at = datetime.now(timezone.utc)
    await session.flush()
    await session.refresh(previous)
    return previous
```

### 4.5 RegistryService facade: AFTER

```python
# app/ml/registry_service.py (excerpt)
class RegistryService:
    def __init__(self, session: AsyncSession) -> None:
        self.session = session

    async def promote_to_production(self, name: str, version: str) -> MLModel | None:
        return await crud.promote(self.session, name, version)

    async def rollback_to_previous(self, name: str) -> MLModel | None:
        return await crud.rollback(self.session, name)

    async def ab_split(self, name: str, version_a: str, version_b: str, percentage: int) -> dict:
        backend = "stub"
        try:
            import importlib
            ft_crud = importlib.import_module("app.crud.feature_toggle")
            flag_name = f"ml_ab_{name}"
            await ft_crud.upsert_toggle(self.session, name=flag_name, rollout_percentage=percentage)
            backend = "feature_toggles"
        except (ImportError, AttributeError):
            pass
        return {"name": name, "version_a": version_a, "version_b": version_b,
                "percentage": percentage, "backend": backend}
```

## 9. User Stories

### 9.1 Core install flow (US-01 .. US-05)

**US-01: Install ML model registry into a clean FastAPI project**
- **As a** ML platform engineer
- **I want** a full artefact registry in one tool call
- **So that** I do not build promote/rollback logic by hand
- **Given:** A FastAPI project with `app/core/config.py`, `app/models/base.py`, `alembic/versions/`, `requirements.txt`

## 12. Rollback Procedure

### 12.1 Code rollback (before deploy)

```bash
git checkout HEAD -- \
  app/core/config.py \
  app/models/__init__.py \
  app/routes/__init__.py

rm -f app/models/ml_model.py
rm -f app/schemas/ml_model.py
rm -f app/crud/ml_model.py
rm -f app/ml/registry_service.py
rm -f app/api/routes/ml_registry.py
rm -f alembic/versions/add_ml_model_registry.py
```

### 12.2 Database rollback (after deploy)

```bash
alembic downgrade -1   # drops ml_models table + its indexes
```

The `downgrade()` function in `alembic/versions/add_ml_model_registry.py` runs:

```python
op.drop_index("ix_ml_models_name_version", table_name="ml_models")
op.drop_index("ix_ml_models_name", table_name="ml_models")
op.drop_table("ml_models")
```

### 12.3 Data preservation before downgrade

**Critical for compliance.** If any `ml_models` row has significance for audits, archive before downgrade:

```sql
CREATE TABLE ml_models_archive_<date> AS SELECT * FROM ml_models;
-- or: COPY ml_models TO '/backup/ml_models_<date>.csv' WITH CSV HEADER;
```

### 12.4 Failure mode: tool partially modified files

```bash
git status --porcelain | grep '^ M' | awk '{print $2}' | xargs git checkout --
find . -name '*.tmp_*' -delete
```

The ast.parse validation loop runs at the end of the success path. Partially-written files may exist on mid-execution failure. Revert modified files and remove created files to restore.

### 12.5 Uninstall validator

```bash
test ! -f app/models/ml_model.py || (echo "MLModel still present" && exit 1)
test ! -f app/ml/registry_service.py || (echo "RegistryService still present" && exit 1)
grep -q "ML_REGISTRY_DEFAULT_FRAMEWORK" app/core/config.py && echo "config still patched" && exit 1
echo "rollback verified"
```
