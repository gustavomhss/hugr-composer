# hugr-fastapi

Framework-free production primitives for generated FastAPI apps.

`hugr-fastapi` is the **runtime dependency** of apps generated by the HuGR
Arsenal skill. The MCP tools (`adapt/extend/*`, `generators/*`) emit code that
imports these primitives directly:

```python
from hugr_fastapi.resiliency import CircuitBreaker
from hugr_fastapi.auth import ...
```

## Design

- **Zero required dependencies.** The core impls are pure Python by contract
  (§A1) — no fastapi/sqlalchemy in the core. Provider glue is opt-in.
- **Namespace layout mirrors the skill's `core/venous/<ns>/` tree.**
- **Extras for provider adapters:**
  - `hugr-fastapi[fastapi]` — FastAPI wiring + SQLAlchemy async
  - `hugr-fastapi[redis]` — Redis glue (events.PubSub)
  - `hugr-fastapi[stripe]` — Stripe glue (billing.Billing)

## Installing

```bash
pip install hugr-fastapi            # core only
pip install "hugr-fastapi[fastapi]" # + FastAPI adapter
```

## Building

```bash
uv build --wheel packaging/hugr-fastapi
```

The wheel source (`hugr_fastapi/`) is emitted from `core/venous/` by the
promotion pipeline's flattening step; only impl + protocol files ship, the
evidence corpus (tests/chaos/metamorphic) stays in the skill repo.
